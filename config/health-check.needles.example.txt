# health-check.needles.txt —— 旧路径清单（一行一个，去掉行首的 # 才生效）
#
# 【放哪里】必须放在 scripts\ 下：脚本读的是  scripts\health-check.needles.txt。
#           放错位置不会报错，但会被当成"没配置"——体检报告会明确告诉你
#           "本节未执行有效检查"，不会给你一个假的绿勾。
#
# 【它做什么】体检时会用 reg query 全注册表搜索这里列出的每个字符串，
#             报告所有仍引用它们的键。迁移/改名之后"系统认不出程序"，多半就是这些引用。
#
# 【填什么】填本机真实的历史路径，例如：
#   - 改名前的用户目录（最常见的失效根源，强烈建议填，哪怕只填这一条）
#   - 迁移前程序所在的旧目录
#
# 【注意】下面的示例**全部注释掉**了。如果原样复制而不修改，脚本会判定
#         "清单为空 / 全是占位符"并报告"本节未执行有效检查"——这是刻意的：
#         宁可告诉你"没查"，也不要给你一个"✓ 无残留"的假绿。
#
# 示例（把尖括号换成你自己的，再删掉行首的 #）：
# C:\Users\<旧用户名>
# D:\OldAppFolder
# D:\Apps\Portable\<搬走前的旧名字>
